# Product demonstration clips

Both clips show actual browser interactions on a local production build of AgileToolHub using fictional notes. They are silent, 24 second H.264 MP4 files at 1080 by 900 pixels. The matching SRT files provide text captions for publication.

| Clip | Workflow | Caption file |
|---|---|---|
| [Bug report demo](bug-report-demo.mp4) | Enter rough checkout notes, generate a structured draft, inspect the result, and download Markdown | [Captions](bug-report-demo.srt) |
| [User story demo](user-story-demo.mp4) | Describe catalog filtering, generate a story draft, inspect the result, and download Markdown | [Captions](user-story-demo.srt) |

The clips contain no private backlog data or real team session links. Their accompanying [post drafts](../posts.md) explain that generated content needs human review. Review the clip, caption, and post together before publishing from the selected account.
