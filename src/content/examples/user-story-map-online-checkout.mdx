## Activities

Use these activities as the backbone of a checkout journey:

1. Discover a product
2. Build the cart
3. Pay for the order
4. Track the order
5. Manage the order

## MVP slice

- View product details
- Add a product to the cart
- Enter payment details
- Confirm the order
- Receive an order confirmation

## Later slices

- Save payment methods
- Apply promotional codes
- Choose delivery windows
- Track shipment status
- Request a refund
